# 👁️ VigilanceAI

Système de surveillance comportementale IA basé sur **YOLOv8** + **GPS réel**.

## Fonctionnalités
- 👤 Score de menace 0–100% par individu
- 🏃 Comportement : marche / course / fuite / surveillance
- 🎒 Objets suspects (couteau, sacs...)
- 🚗 Véhicule de fuite identifié
- 👥 Analyse de foule + alertes surpopulation
- 🗺️ GPS réel (ipinfo + OSM + OpenCage + W3W)

## Niveaux de menace
- 🟢 **GENTIL** (0–34%) · 🟠 **NEUTRE** (35–64%) · 🔴 **SUSPECT** (65–100%)

*Fait par **Mayele***
